Fundamentals

Variables (var, let, const)

Learn how variables store data values and understand differences between variable scopes and declarations.

Data Types

Understand Primitive types (String, Number, Boolean, Null, Undefined) and Reference types (Objects, Arrays).

Perform mathematical arithmetic, logical comparisons, assignment shortcuts, and ternary evaluations.

for (let i = 0; i < 5; i++) { ... }

Encapsulate reusable blocks of logic using function declarations, expressions, parameters, and ES6 arrow functions.

Find the Largest Number

Compares three numbers using conditional operators to identify the maximum value.

function findLargest(a, b, c) {
  if (a >= b && a >= c) return a;
  if (b >= a && b >= c) return b;
  return c;

#05

Calculate Factorial

Calculates the product of all positive integers less than or equal to n (n! = n × (n-1)... × 1).

function factorial(n) {
  let result = 1;
  for (let i = n; i > 1; i--) result *= i;
  return result;
}

Generate Multiplication Table

Creates an arithmetic multiplication table for any given number up to a specified count.

function multiplicationTable(num, limit = 10) {
  for (let i = 1; i <= limit; i++) {

Reverse a String

Inverts the character order of a given string from right to left using JavaScript string methods.

#08

Check Palindrome

Tests if a word, phrase, or number reads the exact same backwards as forwards (e.g., racecar, madam).

function isPalindrome(str) {
  const clean = str.toLowerCase().replace(/[^a-z0-9]/g, '');
  return clean === clean.split('').reverse().join('');
}

#09

Find Sum of Array Elements

Iterates across an array of numbers to calculate the cumulative total sum using reduce().

function sumArray(arr) {
  return arr.reduce((acc, curr) => acc + curr, 0);
}

Count Even Numbers in an Array

Filters through a list of numerical elements and counts how many are evenly divisible by 2.

function countEvenNumbers(arr) {
  return arr.filter(n => n % 2 === 0).length;
